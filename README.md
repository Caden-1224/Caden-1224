## 👋 你好，我是 Caden

我从通信工程出发，正在一步步走向计算机系统。最早和单片机、外设打交道，后来在 Linux 上做多进程和端侧推理；兴趣也从“让一个功能跑起来”，慢慢落到它背后的调度、通信和资源管理上。

我喜欢顺着问题往下看一层：数据在哪里等待？取消之后，旧结果为什么还会回来？一个进程退出，会牵动系统的哪一部分？嵌入式的经历让我对时序、内存和硬件约束比较敏感，而这些问题的答案，大多在软件那一侧。

🎯 **现在的主线是计算机系统。** 我想带着这份硬件直觉，把这些问题放回系统里看；一边补基础，一边把理解放进项目里验证。
